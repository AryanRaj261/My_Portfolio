# Integrattion

> The filename intentionally follows the requested project convention.

## Current integrations

| Integration | Use | Boundary |
| --- | --- | --- |
| Vercel | Production hosting and Git-based deployment | Build/deployment platform; no runtime credentials in the client. |
| GitHub | Source repository and public profile link | External profile/repository links. |
| ThreeUI authored sources | Local interaction studies | Bundled local source and static assets; preserve hashes and paths. |
| Google Fonts | Typography delivery | Public stylesheet requested by the browser. |

## Integration policy

- Prefer local assets or stable first-party integrations for essential portfolio behavior.
- Do not add a third-party script without a user benefit, privacy review, and performance check.
- Keep source-backed study assets local and validate them with the provided verification script.
- Document any new service, its owner, data exposure, fallback behavior, and removal plan in this file.

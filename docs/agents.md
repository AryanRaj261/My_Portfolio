# Agents

## Scope

Coding agents working in this repository should make focused, verifiable improvements to the existing portfolio. They should not replace the portfolio with a generic landing page or invent professional claims, links, clients, or project outcomes.

## Working rules

- Read the relevant source and existing documentation before editing.
- Keep project facts in `src/data/portfolio.js` when practical.
- Preserve the local source-backed interaction studies and their asset paths.
- Use accessible semantic HTML, keyboard-operable controls, and reduced-motion-safe behavior.
- Avoid changing user-owned assets or legacy files unless the requested scope requires it.
- Run the documented quality gates for behavior or visual changes.

## Content rules

- Keep independent concepts labelled as concepts.
- Add public links only when they are verified.
- Keep résumé-backed content factual and specific.
- Do not treat the client-side guide as an AI service or claim that it stores conversations.

## Delivery

Summarize the user-visible result, validation performed, and any remaining dependency on user-provided content such as a custom domain or verified project URL.

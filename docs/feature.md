# Feature Delivery

## Feature definition

A feature is complete only when it improves a clear visitor outcome, works across supported screen sizes, is accessible by keyboard, and does not weaken the portfolio’s factual accuracy or performance.

## Delivery process

1. Identify the visitor need and affected section.
2. Check `prd.md`, `design.md`, and `memory.md` for constraints.
3. Implement the smallest coherent change.
4. Add or update automated coverage when interaction behavior changes.
5. Run lint, build, source verification when applicable, and browser tests.
6. Review copy for accurate project/client attribution.

## Acceptance checklist

- [ ] Clear user benefit.
- [ ] Responsive and keyboard-operable.
- [ ] Reduced-motion behavior considered.
- [ ] No invented claims or destinations.
- [ ] Tests and production build pass.
